# 🤖 LinguistPro - Advanced POS Detector

A modern Desktop Application built with Python that performs deep linguistic analysis using Natural Language Processing.

## ✨ Features

* **Real-time Analysis**: Instant POS tagging for text input.
* **Granular Noun/Verb Detection**: Identifies Proper vs. Common nouns and specific Verb tenses.
* **File Upload**: Support for importing `.txt` files directly.
* **Export Results**: Save your analysis as `.csv` or `.txt` for external research.
* **Modern UI**: Dark-themed, responsive interface built with CustomTkinter.

## 🛠️ Built With

* [Python](https://www.python.org/) - Core programming language.
* [NLTK](https://www.nltk.org/) - Natural Language Toolkit for NLP.
* [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) - Modern GUI library.

## 🚀 Installation & Usage

1. Go to the **Releases** section on the right.
2. Download `main.exe`.
3. Run the file on Windows (No installation required).
